# Python-30-days

                                            Day 1: The Core Mechanics

                                          
Today is about getting a feel for Python's syntax and built-in data structures. We are focusing on:

Dynamic Typing & Variables: No const, let, or var. Just name it and assign it.

Collections: Lists (arrays) and Dictionaries (objects/JSON).

Control Flow: if/else statements and for loops.

Functions: Defined with def, with a nod to Python's optional type hinting so you feel right at home.


                                           Day 2: OOP and Error Handling

lasses & Objects: Blueprints for creating data structures (using class).

The Constructor: The __init__ method, which initializes new objects.

Inheritance: Creating specialized subclasses that inherit from a parent class.

Exceptions: Catching and handling errors gracefully using try, except, and finally.
